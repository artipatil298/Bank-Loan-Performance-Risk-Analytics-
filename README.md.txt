# Bank Loan Risk & Performance Analytics Dashboard

## Project Overview
This project analyzes 38K+ bank loan records using SQL and Power BI to identify loan performance, customer risk, and financial trends.

## Tools Used
- MySQL
- Power BI
- SQL
- DAX

## Key Features
- Data cleaning and preprocessing using SQL
- Handling missing values and duplicates
- Risk segmentation (High Risk / Low Risk)
- KPI analysis
- Interactive Power BI dashboard
- Loan trend and state-wise analysis

## Dashboard Insights
- Total Loan Distribution
- Default Rate Analysis
- State-wise Loan Analysis
- Income Segmentation
- Risk Distribution
- Loan Status Trends

## Files Included
- SQL Queries
- Power BI Dashboard (.pbix)
- Dataset (.csv)
